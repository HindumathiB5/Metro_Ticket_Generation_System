# Metro Ticket Generation System - ServiceNow

## Project Overview
Digitize metro ticket booking using ServiceNow to enable fast, accessible, and automated ticket generation through QR codes. The system allows users to book tickets by selecting stations and travel details, automatically calculates fares, and generates digital tickets instantly.

## Objectives
- Digitize metro ticket booking process using ServiceNow
- Allow users to select stations and travel details through Service Catalog
- Automate fare calculation based on journey
- Generate QR-based digital tickets
- Use Flow Designer to automate validation and notifications
- Send automated confirmation notifications

## Technologies Used
- ServiceNow Platform
- Service Catalog
- Custom Tables
- Flow Designer
- Client Scripts, UI Policies
- JavaScript
- QR Code Integration

## Project Phases
1. Ideation Phase
2. Requirement Analysis
3. Project Design Phase
4. Project Planning Phase
5. Project Development Phase
6. Project Documentation

## How It Works
1. User selects source and destination stations in Service Catalog
2. System calculates fare automatically
3. Flow Designer processes the request
4. Digital ticket with QR code is generated
5. Confirmation notification is sent to user
